# Context

`insite-out` is a public repo at `/mnt/knowledge/insite-out`, remote
`https://github.com/reallife-spark/insite-out.git`, registered in Home's `00_System/github-index.md`.

The project gives models streaming user EEG information interpreted as feedback for an agent. It
acquires streams through the official Neurosity Python SDK and exposes typed feedback events to
agents. The Jetson / TensorRT-DLA / DeepStream material in the originating answer is background
only.
