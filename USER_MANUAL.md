# Using this repo

1. Read `AGENTS.md` (a symlink to `00_System/AGENTS.md`).
2. Read `00_System/CONTEXT.md`, `00_System/MISSION.md`, `00_System/INTENT.md`.
3. Read `05_Knowledge/MEMORY.md` and `02_Daily/PLAN.md`.
4. Read `06_Projects/insite-out/index.md` for scope and owned docs.
5. Before changing stream handling, read `05_Knowledge/references/neurosity-python-sdk-contract.md`.
6. Before changing agent-facing output, read `06_Projects/insite-out/feedback-event-contract.md`.
7. Use `gh` for issues in `reallife-spark/insite-out`; see `docs/agents/issue-tracker.md`.
8. From Home, use `/repo-fitness insite-out` to check the spine and registry pointers.

The engineering-skill setup is already answered in `docs/agents/`; re-run it only if the tracker,
label vocabulary or domain layout changes. Do not commit unless explicitly requested.
